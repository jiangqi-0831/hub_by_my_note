# 构造

观察写题，发现题目的特点
	- 比如说可以通过构造简单的情况，然后变换状态来写
	- 或者是寻找必要条件发现特点，然后再从必要条件来找充分条件
	- 寻找最大最小时可以通过寻找上下界，然后构造一种方法来取到上下界，例如[Cost of a Bracket Sequence](../题目/Cost%20of%20a%20Bracket%20Sequence.md)

# 交互

了解交互的基本概念：
	交互是指通过输入输出进行信息交流来得到信息
	最有效的编码方式**二进制编码**
		经典题目：
			1. [洛谷P1733猜数](https://www.luogu.com.cn/problem/P1733)经典二分交互
			2. [CF679A 100以内合数质数猜解](https://vjudge.net/problem/CodeForces-679A)
			3. [CF843B 有序列表查找](https://codeforces.com/problemset/problem/843/B)
			4. [CF2129C1、2、3 编码](https://vjudge.net/problem#OJId=CodeForces&probNum=2129C&title=&source=&category=all)主要是通过在有限的询问长度内获得信息
	总结一下：
		获得信息-> 获得更多信息->充分利用信息（这就是CF2129C的各个难度进阶）
	
# 通讯
基本概念：
	就是写两侧代码，然后通过输入输出交互（其实还是一种特殊的交互题）
主要讲解了三类：
- 信息加密
- 对应映射
- 多轮交互
