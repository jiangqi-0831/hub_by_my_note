# 线性表
## 数组
### 可变数组
文件头：vector
操作方法：
-定义：vector<数据类型> 名字(初始长度，初始化的值)
	eg：vector<int> v(10,0) 定义了一个长度为10，初始值为0，数据类型为整型的动态数组.
- 增加数字：v.push_back(x)
- 返回数组长度：v.size()
- 重新调增长度：v.resize(长度,增加长度的初始值)
- 迭代器：vector<int>: :iterator it  定义了一个名为it的迭代器
	- v.began()与v.end()均为迭代器
	- v[i] 与 *(v.began()+i) 等价
