**A - 村庄行会**

哼嗯嗯嗯。  
—— 《我的世界》

在漫长的冒险中，史蒂夫偶然发现了一个村民村庄。村庄中的房屋由双向道路连接。总共有 nn 座房屋，编号为 1 到 nn。房屋与道路构成的图是一棵以 1 号顶点为根的有根树*，其中 1 号房屋是市政厅所在位置。

考虑任意一座房屋 v 及其子树‡。对于每个这样的房屋 v 以及每个非负整数 h，考虑在 v 的子树中，与 v 距离恰好为 h 的所有房屋组成的集合。这样的集合称为一个**行会**。例如，当 h=0 时，该行会只包含顶点 v 本身。

在下图示例中，展示了顶点 v=4 的行会。h=0 的行会用红色标记，h=1 用浅蓝色，h=2 用绿色。

![](assets/Village%20Guilds/file-20260716094649798.png)

如果存在一座房屋属于其中一个行会而不属于另一个，则这两个行会视为不同。史蒂夫想知道树中共有多少个不同的非空行会。请帮助他计算。

- 有根树是指其中一个顶点被指定为根的特殊树。  
    † 树是无环连通图。  
    ‡ 顶点 v 的子树是由 v、它的所有后代以及它们之间的所有边构成的子图。
    

---

## 输入

每个测试包含多个测试用例。第一行包含测试用例数 t（1≤t≤e4）。接下来是每个测试用例的描述。

每个测试用例的第一行包含一个整数 n（2≤n≤2⋅e5）—— 村庄中房屋的数量。

第二行包含 n−1n−1 个整数 p2​,p3​,…,pn​（1≤pi​<i），其中 ipi​ 是第 i 座房屋在树中的父节点。

保证所有测试用例的 n 之和不超过 2⋅e5。

---

## 输出

对于每个测试用例，输出一个整数 —— 村庄中不同行会的数量。



## 给出我的代码

```
#include<stdio.h>
int parent[200020],deep[200020],max1[200020],max2[200020];
void exchange(int x,int *max1,int* max2){
	if(x>*max1){
		*max2=*max1;
		*max1=x;
	}else if(x>*max2){
		*max2=x;
	}
}
int main(){
	int _;
	scanf("%d",&_);
	while(_--){
		int n;
		scanf("%d",&n);
		deep[1]=1;max1[1]=0;max2[1]=0;
		for(int i=2;i<=n;i++){
			scanf("%d",&parent[i]);
			deep[i]=1;
			max1[i]=max2[i]=0;
		}
		for(int i=n;i>=2;i--){
			exchange(deep[i],&max1[parent[i]],&max2[parent[i]]);
			deep[parent[i]]=max1[parent[i]]+1;
		}
		/*
		for(int i=1;i<=n;i++){
			printf("i:%d\tdeep:%d\tmax1:%d\tmax2:%d\n",i,deep[i],max1[i],max2[i]);
		}
		*/
		long long ans=n;
		for(int i=1;i<=n;i++){
			ans+=max2[i];
		}
		printf("%lld\n",ans);
		
	}
	
	
	
	return 0;
}
```

## 思路
通过多次尝试，能够发现当你把一个节点的子树合并时，增加工会的个数是此节点子树深度的次大值，因此，使用max1记录节点子树深度的最大值，max2记录次大值
